# AI Prompt Builder

A modern web app for turning rough ideas into clear, structured AI prompts for tools like ChatGPT, Claude, and Copilot.

## Why This Project

AI tools are more useful when the input is specific. This app makes prompt writing faster, clearer, and easier to reuse.

## Highlights

- Central prompt input inspired by modern AI chat interfaces
- Real-time generated prompt preview
- Tone and output format presets
- Copy-to-clipboard interaction
- Responsive layout for desktop and mobile
- Dark mode with a polished, subtle visual style
